# SteamFun / ГАБДД

Шуточное **удостоверение геймера** по Steam64ID: WinForms-пародия на права ГАБДД (Gabe Newell / ГАБДД).

## Ключ API

1. Взять ключ: https://steamcommunity.com/dev/apikey  
2. Сохранить локально (не в git):

```powershell
dotnet user-secrets set "Steam:ApiKey" "ВАШ_КЛЮЧ"
```

или:

```powershell
$env:STEAM_API_KEY = "ВАШ_КЛЮЧ"
```

## Запуск

```powershell
dotnet run
```

Ввод Steam64ID → «Выдать удостоверение». Можно переключать обращение (он / она / они) без повторного опроса Steam. Список друзей — из публичного профиля (кэш в `cache/friends/`).

### Вкладки

| Вкладка | Содержание |
|---------|------------|
| Лицевая / Оборотная | Категории A–O, штрафы, шуточные поля (гражданство, кровь, приметы…) |
| Психопортрет | Диагноз, черты, сильные стороны / риски, статьи обвинения, вердикт |
| Посмотри на себя | Росты по играм: кличка + пан-шутка + часы |
| Кассовый чек | Оценка библиотеки (цены Store RU → US → SteamSpy) и «энергетики» |

Тексты в стиле **Fallout Shelter**: короткие deadpan-описания «как на карточке предмета». Для ~100 популярных игр — отдельный словарь шуток (`GameRoastCatalog`).

Консольный рендерер (`ConsoleLicenseRenderer`) остаётся в коде.

## Кэш

Первый прогон тянет и кладёт на диск:

- жанры Steam Store → `cache/genres/`
- теги SteamSpy → `cache/tags/`
- цены → кэш цен (null не кэшируется)
- друзья → `cache/friends/`
- UI-состояние → `ui-state.json`

Повторные запуски быстрее.

## Что считает приложение

- Ввод: Steam64ID (17 цифр)
- Ачивки: top-10 игр по активности / часам
- Категории: genres + SteamSpy tags + эвристики (в т.ч. Dota/AppId 570 → MOBA)
- Серийная лояльность: Mafia, FromSoft, Witcher и др. (`SeriesAffinity`)
- Баллы нарушений: лимит 12 (бэклог, простой, нулевой пробег…)
- Категория: ≥5 ч → открыта; ≥3 игр и &lt;1 ч → ЛИШЁН
- Цены чека: Store API с фолбэками; энергетики ≈ ИТОГО ÷ 89 ₽

## Структура (коротко)
