# SteamFun / ГАБДД

Шуточное «удостоверение геймера» по Steam64ID. Пока — только текстовый вывод в консоль.

## Ключ API

1. Взять ключ: https://steamcommunity.com/dev/apikey  
2. Сохранить локально (не в git):

```powershell
dotnet user-secrets set "Steam:ApiKey" "ВАШ_КЛЮЧ"
```

или:

```powershell
$env:STEAM_API_KEY = "ВАШ_КЛЮЧ"
```

## Запуск

WinForms-окно (ввод Steam64ID → «Выдать удостоверение»):

```powershell
dotnet run
```

Консольный рендерер оставлен в коде (`ConsoleLicenseRenderer`), UI — вкладки Лицевая / Оборот / Top-10.

Первый прогон тянет:
- жанры Steam Store API → `cache/genres/`
- теги SteamSpy → `cache/tags/`

Повторные запуски быстрее (кэш).

## Что уже зафиксировано

- Ввод: только Steam64ID (17 цифр)
- Ачивки: top-10 игр по часам
- Категории: genres + SteamSpy tags + эвристики по названию
- Баллы: лимит 12  
  - ≥5 игр без запуска → +2  
  - 0 ч за 14 дней → +1  
  - ≥40% библиотеки с нулевым пробегом → +1  
- Категория: ≥5 ч → открыта; ≥3 игр и &lt;1 ч → ЛИШЁН  
- Шуточные поля (гражданство, кровь и т.д.) — после просмотра живых данных
